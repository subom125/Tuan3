Lab 08: JavaScript 1 — Language Foundations

11 Exercise • Bấm vào từng bài để xem kết quả và mã nguồn.

Danh sách Exercise

Exercise 8.1 — Enabling/Disabling JavaScript

Bật/tắt JavaScript và dùng thẻ noscript để kiểm tra.

Exercise 8.2 — Embedded JavaScript

Viết JavaScript trong thẻ script để hiện thông báo.

Exercise 8.3 — External JavaScript

Liên kết tệp JS bên ngoài và xuất dữ liệu.

Exercise 8.4 — Using noscript

Hiện nội dung khi trình duyệt tắt JavaScript.

Exercise 8.5 — Using the Browser Console

Sử dụng console.log, warn, error để gỡ lỗi.

Exercise 8.6 — Using Built-in JavaScript Objects

Làm việc với String, Date, Math và toán tử so sánh.

Exercise 8.7 — Arrays

Sử dụng Array, push, unshift và vòng lặp để tạo lịch.

Exercise 8.8 — JavaScript Functions

Tạo hàm có tham số, trả kết quả và hiểu phạm vi biến.

Exercise 8.9 — Functions as Objects

Sử dụng hàm ẩn danh làm tham số tính thuế.

Exercise 8.10 — Creating JavaScript Objects

Tạo object bằng hàm khởi tạo và phương thức.

Exercise 8.11 — Arrays of Objects

Duyệt mảng đối tượng, thuộc tính và hiển thị cờ.
